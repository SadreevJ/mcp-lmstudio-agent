xUdav — быстрый старт на Windows (после clone, без файлов из .gitignore)
================================================================

Нужно установить отдельно:
  • Python 3.10+ (в PATH)
  • Node.js (нужен npx, для MCP)
  • LM Studio — скачать с https://lmstudio.ai/, один раз открыть приложение

В репозитории после clone не будет: .env, config/mcp/mcp.json — их создаёте локально.

Пульт с кнопками (Windows): дважды щёлкните gui.bat в корне или:
  python scripts\gui_launcher.py
Там же статус LM Studio и шаги 1–6 — можно не набирать команды вручную.

Шаги:

  1. git clone <url> && cd xUdav

  2. copy .env.example .env
     Откройте .env: укажите LMSTUDIO_API_KEY, если в LM Studio включена авторизация API.

  3. python scripts\run_cli.py bootstrap

  4. python scripts\run_cli.py sync-mcp
     (или powershell -ExecutionPolicy Bypass -File scripts\sync-mcp.ps1)
     Появится config\mcp\mcp.json: корень MCP (файлы и shell) = папка АКТИВНОГО проекта в реестре.
     При switch-project / add-project / bootstrap mcp.json тоже перезаписывается; в открытом чате LM Studio
     всё равно переподключите MCP к файлу или начните новый чат.

  5. LM Studio (вручную):
     • Поднимите Local Server, загрузите модель.
     • Новый чат → Per-request MCP → файл:
       <путь_к_клону>\config\mcp\mcp.json

  6. Проекты кладите в workspace\<имя_папки>\ — см. README.
     Активный проект (реестр): scripts\switch-project.bat
     Статус и LM Studio: python scripts\run_cli.py status

  7. Новый чат / восстановление контекста:
     python scripts\run_cli.py brief
     В консоли появится путь к data\context\briefs\<проект>\latest.md —
     вставьте содержимое в LM Studio или откройте файл через MCP.
     Полный бриф: ... brief --format full
     Handoff: ... brief --handoff

Плагин LM Studio «project-filesystem» может подставлять неверный относительный путь;
если ENOENT на …\project-filesystem\workspace — снова выполните sync-mcp (см. config\mcp\README.md).
