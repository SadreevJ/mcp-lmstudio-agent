xUdav — быстрый старт на Windows (после clone, без файлов из .gitignore)
================================================================

Нужно установить отдельно:
  • Python 3.10+ (в PATH)
  • Node.js (нужен npx, для MCP)
  • LM Studio — скачать с https://lmstudio.ai/, один раз открыть приложение

В репозитории после clone не будет: .env, config/mcp/mcp.json — их создаёте локально.

Шаги:

  1. git clone <url> && cd xUdav

  2. copy .env.example .env
     Откройте .env: укажите LMSTUDIO_API_KEY, если в LM Studio включена авторизация API.

  3. python scripts\run_cli.py bootstrap

  4. powershell -ExecutionPolicy Bypass -File scripts\sync-mcp.ps1
     Появится config\mcp\mcp.json с путями к этой машине.

  5. LM Studio (вручную):
     • Поднимите Local Server, загрузите модель.
     • Новый чат → Per-request MCP → файл:
       <путь_к_клону>\config\mcp\mcp.json

  6. Проекты кладите в workspace\<имя_папки>\ — см. README.
     Активный проект (реестр): scripts\switch-project.bat
     Статус и LM Studio: python scripts\run_cli.py status

Плагин LM Studio «project-filesystem» может подставлять неверный относительный путь;
если ENOENT на …\project-filesystem\workspace — снова выполните sync-mcp.ps1 (см. config\mcp\README.md).
